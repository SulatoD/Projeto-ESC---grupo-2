# Cadastro básico

Aplicação de console em Python que pede nome, data de nascimento e idade, e depois exibe os dados.

## Estrutura

```
cadastro_basico/
├── main.py          # ponto de entrada
├── README.md
└── src/
    ├── __init__.py
    ├── entrada.py   # leitura e validação dos dados
    └── saida.py     # exibição dos dados
```

## Como rodar

Requer Python 3.8+. Na pasta `cadastro_basico`:

```
python main.py
```
